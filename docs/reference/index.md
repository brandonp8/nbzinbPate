# Package index

## Model fitting

Fit NB and ZINB regressions by IRLS, Newton-Raphson and EM.

- [`nbreg()`](https://brandonp8.github.io/nbzinbPate/reference/nbreg.md)
  : Negative binomial (NB2) regression
- [`zinbreg()`](https://brandonp8.github.io/nbzinbPate/reference/zinbreg.md)
  : Zero-inflated negative binomial (ZINB) regression
